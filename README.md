### ANPR — результаты тестирования

- Платформа: **RDK X5 (BPU)**
- Производительность: **11–15 FPS**
- Задержка обработки: **около 480 мс** в указанном тестовом режиме
- Точность: **около 80%** на тестовом наборе

Показатели зависят от конфигурации, входного потока и условий тестирования.
